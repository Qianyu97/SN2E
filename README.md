# SN2E
Run "Train.py" to train the Gaussian embedding of SN2E
Run "Tester.py" to get the F1score, PR-AUC from the trained embedding. The visualization result will be stored in the directory "\source"

The datasets SN-depth4 and SN-depth6 are stored in the directory "\data"

Adjust configs in "config.py"
